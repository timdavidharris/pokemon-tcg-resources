# Pokémon TCG Resource Hub

A lightweight, retro-styled web directory and quick-reference utility for Pokémon Trading Card Game players—both competitive and casual.

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live%20Demo-brightgreen)](https://timdavidharris.github.io/pokemon-tcg-resources/)

---

## Features

* **Curated Resource Directory:** Quick access to top competitive meta trackers, deck builders, official rulebooks, and community hubs.
* **Instant Filtering & Search:** Real-time text search and interactive tag-filtering for seamless navigation.
* **Built-in Quick References:** Custom internal rule cheat-sheets for **Special Conditions** and **Turn Actions**.
* **Mobile-Friendly QR Sharing:** Built-in modal generator to easily share the hub with local opponents or league members via QR code.
* **Retro Game Boy Aesthetic:** Pixel-art UI styling complete with pixel borders, scanline overlays, and retro typography.

### Why Use AI to Code this Site?

Most of the code for this site was written by my AI coding buddies. Any of the words, selected sites, or other tools are here because of my creative direction and vision for this site. The point of this site is to share community-based tools with the PTCG community quickly and easily. I chose to leverage AI to put this resource together quickly (this is a passion project that I'm working on in my spare time).
